## 関数

- 定義 **実装済み**
  - export修飾子 **実装済み**
  - exportが付いていない関数にはstaticを付ける
  - main関数はエントリーポイントのためstaticを付けず、戻り値はintにする
- 実装ファイル内で前方宣言を出力していない
  - 後で定義される関数を呼び出すと、C言語のコンパイルで暗黙の関数宣言のエラーになる

## 論理演算

- 論理AND (`&&`)、論理OR (`||`)、論理NOT (`!`) は未実装
  - トークンは生成されるが、パーサーの演算子表には登録していない
  - bool値の扱いと合わせて検討が必要

## 括弧によるグループ化

- **実装済み**
- CEmitterは括弧を付けずに平坦に出力するため、グループ化はノードとして保持している
  - AST: `SyntaxGroupExpression` / Holo IR: `HoloGroupExpr` / C IR: `CGroupExpr`
  - ソースに書かれた括弧は冗長なものも含めてそのまま出力される
